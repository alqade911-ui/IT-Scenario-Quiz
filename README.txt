قرارك التقني - لعبة مواقف تكنولوجيا المعلومات

التشغيل:
npm install
npm start
ثم افتحي http://localhost:3000

اللعب من عدة أجهزة على نفس الشبكة:
شغلي السيرفر على جهاز واحد، ثم افتحي من الأجهزة الأخرى:
http://IP-ADDRESS:3000

لوحة الصدارة مشتركة ومحدثة مباشرة. النتائج محفوظة في ذاكرة السيرفر أثناء تشغيله.
